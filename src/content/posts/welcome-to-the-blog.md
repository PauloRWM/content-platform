This is the first post on our content platform. If you can read it on the live
site, the whole pipeline works: someone wrote it as a Markdown file, opened it
for review, got it approved, and merged it — and it published itself.

## Why this exists

We're building a content business, which means publishing has to be **easy,
reliable, and safe**. Easy so anyone on the team can do it without an engineer.
Reliable so a change never takes the site down. Safe so nothing goes live until
a second person has looked at it.

## How you publish

Every post is a plain-text Markdown file. To get one live you:

1. **Draft** — create your post from the template.
2. **Review** — open a pull request so a teammate can read it and approve.
3. **Publish** — flip the `draft` switch to `false` and merge.

The full step-by-step (including the browser-only path, no software to install)
is in the project README under **"The publishing workflow"**.
